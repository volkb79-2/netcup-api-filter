# `.env.workspace`

`.env.workspace` is a gitignored file generated by
`.devcontainer/finalize.post.d/10-netcup-setup.sh`. It carries workspace-specific paths and
detected edge/network facts for shell workflows and the CIU render context. It is regenerated when
the devcontainer is prepared; do not edit it by hand or copy its values into tracked files.

The file is not a secret store. It must not contain application, provider, mailbox or basic-auth
credentials. Operator-supplied delegated-zone facts belong in `.env.operator`; the SSHFS and
webhoster URL route belongs in `.env.webhoster`; live-check credentials belong in `.env.live` or
the later CIU secret-delivery flow.

The complete ownership and reader map is in
[`CONFIGURATION_GUIDE.md`](CONFIGURATION_GUIDE.md#environment-file-layout). The generated public
FQDN is described in [`FQDN_DETECTION.md`](FQDN_DETECTION.md).
